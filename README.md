# 1С:Профессионал: исходники без скриншотов (базовая версия)

Это **оригинальные исходные файлы** из пользовательского `Sigma_Learning_programm.rar`, без изменений в `app.js`, `index.html`, `server.py`, `server_exe.py`, `dataset.json`, `questions_raw.json` и остальных файлах. Добавлены только `.gitignore`, этот README и `TASK_FOR_BOT.md`.

В ZIP **нет** скриншотов (ни `.jpg`, ни `.png`) и бинарных EXE/сборочных кэшей. В `dataset.json` сохраняются ссылки на отсутствующие изображения (это важно для независимой диагностики).

Содержимое: 977 вопросов, 14 разделов. При запуске готового EXE из `dist/` возможно отсутствие вопросов: `server_exe.py` ищет `dataset.json` рядом с EXE. Наличие «977» в интерфейсе не подтверждает загрузку: число прописано в HTML. Требуется расследование и проверяемое исправление.

## Проверка

```bash
python server.py
```

Откройте адрес, напечатанный в консоли (`http://localhost:8765` по умолчанию). Не запускайте `index.html` двойным кликом.

**Внимание:** `build_dataset.py` зависит от исходных изображений и абсолютных путей Windows; повторно не выполняйте без необходимости.
